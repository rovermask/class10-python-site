Q1BWhat is a module in Python?
  1. AA function that runs automatically when Python starts
  2. BA .py file containing code, such as functions and variables, that can be imported
  3. CA folder that holds several Python files
  4. DA Python keyword that starts a program

Any .py file is a module. A folder of modules is a package.

  2. BA folder of modules, usually with an __init__.py file inside

A package groups related modules into a folder.
